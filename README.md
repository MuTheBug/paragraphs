# JusticeCMS — Interactive Web Development Course

An interactive, project-based course that teaches the full Python web stack
by building a real Court Management System from scratch.

**Open `index.html` in your browser to start.**

## Stack Covered
- **FastAPI** (Python) — REST API backend
- **PostgreSQL** — Relational database
- **Celery + Redis** — Background tasks & notifications
- **Vanilla HTML/CSS/JS** — Frontend (no frameworks)
- **Linux + Docker + Nginx** — Deployment infrastructure

## How to Use
1. Open `index.html` in any modern browser
2. Click **Start Learning**
3. Work through modules in order — each builds on the previous
4. Every module has code examples, quizzes, and exercises
5. Your progress is saved in the browser automatically
